# Restaurant API
Build .NET 8 APIs in Clean Architecture, user Identity system and Azure deployment using CI/CD .
# Description
- Project Description: Building a Scalable and Maintainable RESTful API Using ASP.NET Core 8 and Azure

- This project demonstrates my ability to develop a robust, high-performance RESTful API by leveraging ASP.NET Core 8, Clean Architecture principles, and Azure services. Below are the key features and implementations of the project:

# Core Functionalities
- RESTful API Design: Created endpoints adhering to REST principles for creating, retrieving, updating, and deleting resources.
- Clean Architecture Implementation: Adopted Clean Architecture to organize the project for maintainability and scalability. The solution was structured with distinct layers for presentation, application, domain, and       infrastructure.
- DTO Mapping and Validation: Ensured data integrity by implementing efficient DTO mapping and validation using FluentValidation.
# Infrastructure Setup
- Database Management: Integrated Microsoft SQL Server and configured Entity Framework Core for seamless interaction with the database. Included a data-seeding mechanism to populate test data.
- Authentication and Authorization: Secured the API with user authentication and role-based access control using ASP.NET Identity and custom claims.
# Advanced Features
- Nested Resource Management: Developed support for sub-entity management within the API while adhering to RESTful standards.
- Pagination and Sorting: Enhanced performance for large datasets with efficient pagination and sorting mechanisms.
- Global Exception Handling: Implemented centralized error handling to ensure robust and user-friendly error responses.
- Automated Documentation: Used tools like Swagger to generate clear, interactive API documentation.
# Performance and Observability
- Logging: Configured Serilog for detailed logging of API activity to aid troubleshooting and monitoring.
- Testing and Deployment
- Testing: Implemented unit and integration tests to ensure functionality and prevent regressions.
# Deployment: Deployed the API to Azure App Service with Azure SQL as the database backend.
- CI/CD Pipeline: Built a CI/CD pipeline using Azure DevOps to automate builds, testing, and deployment.

This project exemplifies modern development practices in building secure, scalable, and maintainable APIs, highlighting both technical proficiency and an adherence to best practices.
